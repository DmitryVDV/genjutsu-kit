Getting started

Three steps to the first question

  1. 01

    Open the folder in Claude Code

    The genjutsu-kit folder is already a project: cd genjutsu-kit && claude in the terminal, or the Code tab in Claude Desktop — see below. To use it in another project, copy .claude/skills/genjutsu there.

    Add your fal.ai key

If something goes wrong

Chat mode won't work

In regular Chat (the bubble icon), code runs in the cloud: your folder, key and ffmpeg aren't there. Only Code with the Local environment.

It says “ffmpeg: НЕТ” (not found) even though it's installed

Quit Claude completely (Cmd+Q) and open it again. If that doesn't help, add the /opt/homebrew/bin folder to PATH in the Local environment settings (the gear icon by the input box).

Generation takes a long time

A video takes 5–16 minutes to render in the background. Don't close the app and don't let your Mac go to sleep. You can follow progress in the task panel: menu Views → Tasks.

The key accidentally went into the chat

Delete it at fal.ai/dashboard/keys, create a new one and put it in .env: the key can't be removed from the chat history.

What we learned on the first clip

Why it works this way

Kling, not Seedance

Genjutsu, by all signs, runs on Seedance. But on fal, Seedance rejects photos of real people: “likenesses of real people”. Kling O3 edit accepts real faces and keeps the clothes of both looks and the shot changes.

Hands come first

Without a separate paragraph in the prompt, Kling passed a hand through a face and mixed up fingers. With the “HANDS ARE THE PRIORITY…” paragraph, the fingers matched the original. The script adds it automatically.

No scene frame on a wide shot

Kling takes the shot size from the reference image: a wide shot turned into a medium one. Without a scene frame, the wide shot stayed wide.

Tested on September 27, 2026, with Hotel Lobby: two looks, 15 seconds, Kling O3 edit on fal.ai. Selfies and avatars go to fal storage behind a link that can't be guessed. If the source uses someone else's track, Instagram may mute the sound.
