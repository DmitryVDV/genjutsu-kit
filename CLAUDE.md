# Genjutsu через fal.ai

Этот проект повторяет чужое видео или тренд с пользователем вместо исполнителей: он играет обоих в двух образах. Движения, мимика и камера берутся из видео, лицо и одежда — из его селфи.

- На любую просьбу про видео, тренд, аватар или перекаст — скилл `genjutsu` (`.claude/skills/genjutsu/SKILL.md`). Иди по его шагам и задавай вопросы по одному.
- Готовые shell-утилиты — `tools/`: айфон, сравнение, звук, лист кадров, скачивание, подготовка фото.
- Инструкция для человека — `инструкция.html`.
- Ключ fal — только в `.env` (`FAL_KEY=…`). Не открывай `.env` файловыми инструментами и не печатай ключ.
- Результаты — `genjutsu/` (в git не идут).
